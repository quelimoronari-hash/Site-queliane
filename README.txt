SITE QUELIANE MORONARI — PRONTO PARA VERCEL

1. Entre em vercel.com e faça login.
2. Clique em Add New > Project.
3. Importe esta pasta pelo GitHub, ou use o Vercel CLI.
4. Não precisa configurar framework ou build command: é um site estático.
5. Publique.

Arquivos:
- index.html: conteúdo e links
- styles.css: visual responsivo
- script.js: menu mobile e animações
- vercel.json: configuração Vercel

Observação sobre as fotos:
O site usa as duas imagens já públicas do site de referência via URL:
https://queliane-moronari.vercel.app/assets/hero-wide.jpg
https://queliane-moronari.vercel.app/assets/portrait.jpg

Se quiser tornar o novo site totalmente independente do antigo, baixe essas duas imagens e coloque-as em /assets, depois altere os dois caminhos no index.html para assets/hero-wide.jpg e assets/portrait.jpg.
